# 對戰測試版 · 2026-11-14

## 已實作入口
首頁 → 對戰模式 → 自動建立房間，直接顯示房號、成員與邀請連結。
朋友開啟連結、填暱稱即可加入。房主開賽後所有玩家自動進入各自操作頁；
個人完成後回房間等待，全員完成再公布排名。

## 比賽規則
- 玩家模式：2–4 人；人機模式：1 人對戰 0050 定期定額。
- 每人 NT$1,000,000，現股、不放空、不槓桿。輸入單位為股。
- 由人工熱門候選池隨機選股票（2330、2317、2454、2303、2603、2881），非即時熱門排行。
- 隨機抽選 2019–2024 的 24 個共同交易日，股票與 0050 日期必須對齊。
  暫不跨 2025 年，避免 0050 分割事件被當成價格損失。未提供權息調整。
- 24 根 × 8 秒 = 192 秒。**沒有每根決策倒數**。
- 每人最多三次 Option，每次十秒後自動恢復；上限 222 秒，含三秒起跑倒數約 225 秒。
- 共同伺服器截止為開賽後 240 秒。離線者在下一次房間讀取時也會自動完成；
  不會要求離線者重新上線才能結算。背景作業不是常駐排程。
- 不同步個人 K 線、持倉、操作。共用記分板每秒更新伺服器計算的總資產報酬率。
  各玩家可能因 Option 處於不同 Replay 時點，記分板並非同一模擬日期的比較。
- 市價按伺服器收到委託時的模擬價格成交。限價按模擬路徑首次觸及成交，
  跳空若更有利則按開盤價成交。待成交委託預留現金／股數，可取消。
- 訂單顯示預估金額，並不保證市價最終成交金額。區間結束取消掛單、平倉。
- 0050 對手於第 1、6、11、16、21 個交易日開盤各投入二十萬元，整股買入；
  剩餘與尚未投入現金都計入資產。這是五交易日一次的等額投入比較，不是月扣款。
- 最終依總盈虧排名，同盈虧並列。另列報酬、回撤、成交筆數、賣出樣本、勝率、獲利因子。
  勝率按賣出成交分筆計算；樣本不足三筆明確標示，不做人格能力定論。
- 未計手續費、交易稅、滑價、股息。只比較價格報酬，不能視為真實投資績效。
- 可勾選明確標示的合成資料試玩。歷史行情失敗不會默默改用示範資料。

## 實作與資料
- battle/engine.py：獨立的對戰帳務與時鐘；保留舊單人交易引擎，未替換單人模式。
- battle/store.py：SQLite 共用房間、交易鎖、玩家 token、冪等操作；不向其他玩家回傳完整帳本。
- battle/market.py：開賽前載入固定行情與資料指紋，下載耗時不計入賽事。
- battle/frontend/index.html：原生 canvas 與 requestAnimationFrame，約 30 FPS；
  每秒更新摘要，不對每個動畫畫格重跑 Streamlit。
- pages/3_多人競賽.py：房間、手機操作頁、等待與結算。
- app.py：對戰優先，保留單人模式與原有成績單。

本機預設資料庫在 .battle-data/rooms.sqlite3，可用 ONION_BATTLE_DB 改路徑。
SQLite 僅適合同一執行個體的測試房間；網站重啟、換主機或多執行個體不能保證保留／共享。
房間建立後超過 24 小時，在建立新房時清除。刷新／關閉後若 Session 遺失，
目前不能恢復玩家身分；不在邀請連結放入私人 token。
這不是防作弊競賽：為提供流暢動畫，完整題目行情會傳到瀏覽器。
不可用於獎金賽、正式帳務或需要不可竄改成績的用途。

## 執行
沿用 run_local.ps1，或安裝 requirements.txt 後執行：
python -m streamlit run app.py
手機連同一 Wi-Fi 並使用電腦 LAN IP 時，啟動參數需加 --server.address 0.0.0.0；
是否開放防火牆由使用者自行決定，不自動更改防火牆規則。

python tests/check_battle_ui.py
python tests/check_streamlit.py
