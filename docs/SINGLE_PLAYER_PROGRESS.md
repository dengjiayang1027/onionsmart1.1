# 單人模式進度 · 2026-10-11

目前為本機修改，未推送或部署。

## 已完成

- 交易員頁加入回主選單按鈕，離開時停止動態播放。
- 保留 Manual Replay +1/+5。
- Dynamic Replay 三段插值使用完整 8 秒，最後一根完成才自動平倉與顯示成績。
- 每根預設兩次、每次五秒決策倒數，可設定 0–4 次與 1–30 秒。
- 決策點只使用時間進度，不讀取價格或轉折；與模擬路徑極值時點錯開。
- 編輯交易先凍結價格；送出／取消後依原本播放狀態恢復。
- B：準備買入做多；S：準備賣出做空；Enter：送出待確認交易。
- 空白：Dynamic Replay 開始／暫停。Manual Replay 保留自行點擊逐根前進。
- 待送出面板顯示方向、數量與凍結價格；無待送出交易時 Enter 按鈕停用。
- requirements.txt 要求 Streamlit >=1.60，使用原生 st.button shortcut。

## 驗收

以 run_local.ps1 啟動，進入交易員頁：

1. Manual 下一根／+5，確認日期與索引前進。
2. 切換 Dynamic，空白開始／暫停。
3. B 或 S 後確認 K 線不動，修改數量、理由、SL/TP，Enter 送出。
4. 從播放中準備交易，送出後恢復；從暫停中準備交易，送出後保持暫停。
5. 決策倒數結束續播；最後一根完整形成後顯示成績單。
6. 回主選單返回首頁。

自動驗收：5 個引擎測試通過；Streamlit AppTest 通過首頁、Manual +1/+5、準備買入不成交、確認成交、平倉、模式切換及暫停狀態下做空。
AppTest 不模擬真實鍵盤、瀏覽器導覽或圖表動畫；上述瀏覽器流程尚未人工驗收。
