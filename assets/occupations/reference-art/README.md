## 六項能力

- 守：控制虧損與資產回撤。
- 效：承擔風險後取得報酬的效率。
- 買：判斷買進時機。
- 賣：判斷賣出時機。
- 盈：守住浮盈、減少獲利回吐。
- 穩：維持不同交易階段的穩定表現。
